{"tool":"finish","answer":"..."} ends the turn. Report actual changes and observed verification. If blocked, set "blocked":true and name the missing input or dependency.

Use relative paths. Work directly in the supplied workspace. A failed action is recorded with its reason. Read the result before choosing the next action. Do not repeat a failed action unchanged.
